Отправка обычного текстового сообщения клиенту из ваших систем: в WhatsApp, Instagram, Telegram или виджет на сайте. Сообщение уходит от имени оператора, так же как ответ менеджера из монитора: оно появляется в диалоге и в мониторе, попадает в подключённую CRM, а ИИ-агент в этом диалоге встаёт на паузу.

## Эндпоинт

```
POST https://microservice.pleep.app/api/v1/messages/send-message
```

## Заголовки

| Заголовок | Значение | Обязательный |
|-----------|----------|--------------|
| `X-API-Key` | Ваш API-ключ | Да |
| `Content-Type` | `application/json` | Да |

## Кому писать

Диалог можно указать двумя способами:

- **`thread_id`** работает в любом канале. Это тот же идентификатор диалога, что в [этапах лида](/ru/api/leads), в вебхуке [`lead.status_changed`](/ru/api/webhooks-outgoing), в [получении диалогов](/ru/api/get-threads) и в ссылке на диалог в мониторе.
- **`bot_id`, `channel` и `phone`** работают только для WhatsApp Business API: номер телефона определяет клиента только в WhatsApp.

Сообщение уходит в уже существующий диалог. Начать новый диалог в WhatsApp можно только шаблоном через [отправку шаблонного сообщения](/ru/api/send-template).

## Когда можно писать

| Канал | Когда можно писать обычным текстом |
|-------|------------------------------------|
| WhatsApp Business API (`waba_coexistence`, `waba`) | В течение 24 часов после последнего сообщения клиента. Дальше только шаблоном через [отправку шаблонного сообщения](/ru/api/send-template) |
| Instagram | В течение 24 часов после последнего сообщения клиента. Шаблонов в Instagram нет: дождитесь, пока клиент напишет снова |
| Личный аккаунт Telegram, подключённый официально, через настройки Telegram | В течение 24 часов после последнего сообщения клиента |
| Telegram-бот, личный аккаунт Telegram со входом по номеру телефона, WhatsApp через Green API или Wazzup, виджет на сайте | В любое время |

Если окно закрыто, сообщение не отправляется, и API сразу возвращает `422 WINDOW_CLOSED`. Диалоги голосового агента по телефону текст не принимают: вернётся `422 CHANNEL_NOT_SUPPORTED`.

## Тело запроса

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `thread_id` | string | Да, если нет `phone` | Идентификатор диалога в любом канале, например `thread_0765c2bd-980d-4c65-aeea-d04069646be5` |
| `bot_id` | string | Да, если нет `thread_id` | Bot ID номера WhatsApp. Где его взять, описано в шаге 3 [отправки шаблонного сообщения](/ru/api/send-template) |
| `channel` | string | Да, если нет `thread_id` | `waba_coexistence` или `waba` |
| `phone` | string | Да, если нет `thread_id` | Номер клиента в международном формате, например `+77001234567`. Плюс, пробелы и дефисы можно оставить |
| `text` | string | Да | Текст сообщения, до 4096 символов. В Instagram до 1000 байт, это около 500 букв кириллицы |

Передавайте что-то одно: `thread_id` или `phone`. Если придут оба, вернётся `422`.

## Примеры

### По идентификатору диалога, любой канал

```bash
curl -X POST https://microservice.pleep.app/api/v1/messages/send-message \
  -H "Content-Type: application/json" \
  -H "X-API-Key: pk_live_ваш_ключ" \
  -d '{
    "thread_id": "thread_0765c2bd-980d-4c65-aeea-d04069646be5",
    "text": "Добрый день! Ваш заказ готов к выдаче."
  }'
```

### По номеру телефона, WhatsApp

```bash
curl -X POST https://microservice.pleep.app/api/v1/messages/send-message \
  -H "Content-Type: application/json" \
  -H "X-API-Key: pk_live_ваш_ключ" \
  -d '{
    "bot_id": "your-bot-id",
    "channel": "waba_coexistence",
    "phone": "+77001234567",
    "text": "Добрый день! Напоминаем о встрече завтра в 11:00."
  }'
```

## Ответ

```json
{
  "ok": true,
  "data": {
    "thread_id": "thread_0765c2bd-980d-4c65-aeea-d04069646be5"
  }
}
```

`thread_id` это диалог, в который ушло сообщение. Тот же идентификатор возвращает [получение диалогов](/ru/api/get-threads) и принимает [set-ai](/ru/api/leads).

`ok: true` значит, что сообщение принято и поставлено в отправку, а не что клиент его уже получил.

## ИИ-агент после сообщения

Сообщение через API считается ответом оператора. Если в расширении [Автопереключение](/ru/configuration/operator-settings) включено «Ставить ИИ на паузу, когда вы отвечаете сами» (по умолчанию включено), агент в этом диалоге встаёт на паузу и больше не отвечает клиенту.

Вернуть агента можно через [set-ai](/ru/api/leads) с `ai_enabled: true` или переключателем в мониторе. Если в Автопереключении также включено «Включать ИИ обратно, когда вы закончили», агент вернётся сам через указанное время.

## Коды ошибок

| HTTP-статус | Код ошибки | Описание |
|-------------|------------|----------|
| 401 | `UNAUTHORIZED` | Отсутствует или недействителен API-ключ |
| 404 | `BOT_NOT_FOUND` | Бота с таким `bot_id` нет в аккаунте, которому принадлежит API-ключ. Проверьте `bot_id`, `channel` и то, что ключ создан в аккаунте владельца номера (см. [API-ключи](/ru/api/api-keys)) |
| 404 | `THREAD_NOT_FOUND` | Диалога с таким `thread_id` нет в аккаунте ключа, или клиент с этим номером ещё не писал на этот номер WhatsApp |
| 409 | `CHANNEL_NOT_CONNECTED` | Канал этого диалога больше не подключён |
| 422 | `VALIDATION_ERROR` | Нет `text`, не указан диалог, переданы сразу `thread_id` и `phone`, неверный `channel`, номер не похож на телефон, текст длиннее 4096 символов или длиннее 1000 байт в Instagram |
| 422 | `WINDOW_CLOSED` | В канале с окном 24 часа клиент писал больше суток назад или ещё не писал. В WhatsApp отправьте шаблон |
| 422 | `CHANNEL_NOT_SUPPORTED` | Диалог голосового агента по телефону, писать в него текст некуда |
| 429 | `RATE_LIMITED` | Слишком много запросов. Лимит: 120 запросов в минуту на API-ключ |
