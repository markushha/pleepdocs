Отправка обычного текстового сообщения клиенту в WhatsApp из ваших систем. Сообщение уходит от имени оператора, так же как ответ менеджера из монитора: оно появляется в диалоге и в мониторе, попадает в подключённую CRM, а ИИ-агент в этом диалоге встаёт на паузу.

## Эндпоинт

```
POST https://microservice.pleep.app/api/v1/messages/send-message
```

## Заголовки

| Заголовок | Значение | Обязательный |
|-----------|----------|--------------|
| `X-API-Key` | Ваш API-ключ | Да |
| `Content-Type` | `application/json` | Да |

## Когда можно писать обычным текстом

WhatsApp доставляет обычный текст только в течение 24 часов после последнего сообщения клиента. Если клиент молчит дольше или ещё ни разу не писал на этот номер, начните разговор шаблоном через [отправку шаблонного сообщения](/ru/api/send-template). Когда клиент ответит, снова можно писать обычным текстом.

## Тело запроса

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `bot_id` | string | Да | Bot ID номера WhatsApp. Где его взять, описано в шаге 3 [отправки шаблонного сообщения](/ru/api/send-template) |
| `channel` | string | Да | `waba_coexistence` или `waba` |
| `phone` | string | Да | Номер клиента в международном формате, например `+77001234567`. Плюс, пробелы и дефисы можно оставить |
| `text` | string | Да | Текст сообщения, до 4096 символов |

## Пример

```bash
curl -X POST https://microservice.pleep.app/api/v1/messages/send-message \
  -H "Content-Type: application/json" \
  -H "X-API-Key: pk_live_ваш_ключ" \
  -d '{
    "bot_id": "your-bot-id",
    "channel": "waba_coexistence",
    "phone": "+77001234567",
    "text": "Добрый день! Напоминаем о встрече завтра в 11:00."
  }'
```

## Ответ

```json
{
  "ok": true,
  "data": {
    "thread_id": "thread_0765c2bd-980d-4c65-aeea-d04069646be5"
  }
}
```

`thread_id` это диалог, в который ушло сообщение. Тот же идентификатор возвращает [получение диалогов](/ru/api/get-threads) и принимает [set-ai](/ru/api/leads).

`ok: true` значит, что сообщение принято и поставлено в отправку, а не что WhatsApp уже доставил его клиенту.

## ИИ-агент после сообщения

Сообщение через API считается ответом оператора. Если в расширении [Автопереключение](/ru/configuration/operator-settings) включено «Ставить ИИ на паузу, когда вы отвечаете сами» (по умолчанию включено), агент в этом диалоге встаёт на паузу и больше не отвечает клиенту.

Вернуть агента можно через [set-ai](/ru/api/leads) с `ai_enabled: true` или переключателем в мониторе. Если в Автопереключении также включено «Включать ИИ обратно, когда вы закончили», агент вернётся сам через указанное время.

## Коды ошибок

| HTTP-статус | Код ошибки | Описание |
|-------------|------------|----------|
| 401 | `UNAUTHORIZED` | Отсутствует или недействителен API-ключ |
| 404 | `BOT_NOT_FOUND` | Бота с таким `bot_id` нет в аккаунте, которому принадлежит API-ключ. Проверьте `bot_id`, `channel` и то, что ключ создан в аккаунте владельца номера (см. [API-ключи](/ru/api/api-keys)) |
| 404 | `THREAD_NOT_FOUND` | Клиент с этим номером ещё не писал на этот номер WhatsApp. Начните разговор шаблоном |
| 422 | `VALIDATION_ERROR` | Нет `bot_id`, `phone` или `text`, неверный `channel`, номер не похож на телефон или текст длиннее 4096 символов |
| 422 | `WINDOW_CLOSED` | С последнего сообщения клиента прошло больше 24 часов, или клиент ещё не писал. Отправьте шаблон |
| 429 | `RATE_LIMITED` | Слишком много запросов. Лимит: 120 запросов в минуту на API-ключ |
