The Pleep Public API connects Pleep to your own systems: send WhatsApp template messages, export conversations, read and change a lead's funnel stage, and receive events as they happen.

## What you can do with the API

- **Send template messages** — trigger WhatsApp messages from your own systems without logging into the dashboard
- **Batch sending** — send to multiple recipients in a single request
- **Export conversations** — pull message history by phone or date range, with each lead's current stage
- **Manage lead stages** — read and change a lead's funnel stage by conversation id
- **Receive events** — outgoing webhooks instead of polling the API
- **Support for both WABA channels** — works with WABA Coexistence (Meta Cloud API) and legacy WABA (GupShup)

## Getting started

1. [Create an API key](/en/api/api-keys) in your personal cabinet
2. Pick your endpoint: [Send Template Message](/en/api/send-template), [Get Conversation Threads](/en/api/get-threads), [Lead Stages](/en/api/leads) or [Outgoing Webhooks](/en/api/webhooks-outgoing)
3. Make your first API call

<Callout title="API version">
  The current API version is **v1**. All endpoints are prefixed with `/api/v1/`.
</Callout>

## Authentication

All API requests require an API key passed in the `X-API-Key` header. You can create and manage API keys in your [personal cabinet → Developers](https://app.pleep.app/settings/developers).

```
X-API-Key: your-api-key
```

<Callout title="Keep your API key safe">
  Your API key is shown only once when you create it. Store it securely. If you lose it, revoke the old key and create a new one.
</Callout>

## Rate limits

By default the API allows **30 requests per minute** per API key. [Lead stage](/en/api/leads) endpoints have their own budget of **60 requests per minute**. Exceeding either returns a `429` with the `RATE_LIMITED` code. Wait and retry after a short delay.

Outgoing webhooks are not subject to this limit: there Pleep calls you, not the other way round.

## Base URL

All API requests should be sent to your Pleep instance's base URL:

```
https://microservice.pleep.app/api/v1/
```
